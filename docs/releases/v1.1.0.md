## Kabrilla 1.1.0

Terminal integrada, menú superior y barra de estado. Todo lo de la 1.0.0 sigue funcionando igual; tus namespaces,
credenciales y configuración se conservan.

### Novedades
- **Terminal integrada** (estilo VS Code): menú **Terminal**, botón **>_ Terminal** de la barra de estado o
  `Ctrl+ñ` (`Ctrl+\`` en teclado inglés).
  - Panel inferior con varias terminales de PowerShell (**+** abre otra), común a todas las pestañas.
  - Funciona como una terminal externa: usa tu `~/.kube/config`, tus credenciales de `~/.aws` y tu `PATH`, así que
    `kubectl`, `aws`, `helm` o `k9s` se usan igual que fuera de Kabrilla.
  - Muestra el **contexto actual de kubectl** (cluster · namespace) y se actualiza si lo cambias con
    `kubectl config use-context`.
  - **Ocultar** deja las terminales corriendo; `exit` o la ✕ cierran una; al cerrar Kabrilla se cierran todas.
- **Menú superior**: **Archivo** (agregar namespace, credenciales AWS, abrir la configuración), **Ver** (mostrar u
  ocultar el panel de clusters y el de terminal), **Terminal** y **Ayuda** (carpeta de logs, notas de la versión,
  acerca de).
- **Barra de estado**: tu usuario de Windows, el contexto de kubectl, acceso a la terminal y la versión.
- **Configuración editable**: `%USERPROFILE%\.kabrilla\application.properties` (menú **Archivo → Abrir archivo de
  configuración**). Se crea con las opciones comentadas; por ejemplo, para usar otro shell en la terminal:
  `kabrilla.terminal.shell=pwsh.exe -NoLogo`. Reinicia la app para aplicar los cambios.

### Cambios: dónde quedaron los botones del panel izquierdo
| Antes | Ahora |
|---|---|
| Crear namespace | **+** junto a "CLUSTERS", o clic derecho sobre un cluster → **Agregar namespace…** (ya con ese cluster elegido) |
| Agregar credenciales | Clic derecho sobre el cluster → **Credenciales AWS…** (o menú **Archivo**) |

### Instalación
1. Descarga `kabrilla-1.1.0-win-portable.zip` (abajo, en *Assets*) y descomprímelo.
2. Ejecuta `Kabrilla\Kabrilla.exe`. No necesita Java instalado.
3. Requisitos: **AWS CLI v2** en el PATH y `~/.kube/config` con los clusters EKS. Para usar `kubectl` en la terminal
   integrada, tenerlo instalado igual que para una terminal normal.

Si vienes de la 1.0.0: borra su carpeta y descomprime esta. Tus datos siguen en `%USERPROFILE%\.kabrilla\`.

Windows puede mostrar "Windows protegió su PC" porque el ejecutable aún no está firmado: *Más información* →
*Ejecutar de todas formas*.

### Reportar problemas
Incluye la versión (barra de estado o título de la ventana), qué hiciste y el archivo `kabrilla.log` (menú
**Ayuda → Abrir carpeta de logs**).
