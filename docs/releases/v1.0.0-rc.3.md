## Kabrilla 1.0.0-rc.3 — Release Candidate

Tercera versión candidata. Mismas funciones que la rc.2, con mejor diagnóstico de errores:

### Cambios
- **Errores con detalle en `kabrilla.log`**: cada fallo queda con su contexto (cluster, namespace, deployment, pod,
  container) y la traza completa. Antes varios errores se perdían porque la app no tiene consola.
- **Mensajes de error más claros en la app**: dicen qué falló y por qué (p. ej. "Error al cargar deployments: …
  → AWS CLI no devolvió token: ExpiredToken …"), en vez de solo "Error al cargar deployments".
- Si no se pueden guardar las credenciales o un namespace, la app lo avisa (antes decía "guardado" aunque fallara).
- La pestaña Pods ya no se queda "cargando" cuando falla, y muestra el motivo.
- Arranque un poco más rápido y log sin avisos repetidos de versión de FXML.

### Problemas conocidos
- Si las credenciales AWS vencen y pegas unas nuevas, puede que no apliquen hasta reiniciar la app (o hasta
  ~14 minutos). Se corrige en la siguiente versión.

### Instalación
1. Descarga `kabrilla-1.0.0-rc.3-win-portable.zip` (abajo, en *Assets*) y descomprímelo.
2. Ejecuta `Kabrilla\Kabrilla.exe`. No necesita Java instalado.
3. Requisitos: **AWS CLI v2** en el PATH y `~/.kube/config` con los clusters EKS
   (`aws eks update-kubeconfig --name <cluster> --region <region>`).

Si vienes de una rc anterior: borra su carpeta y descomprime esta. Tus namespaces y credenciales siguen en
`%USERPROFILE%\.kabrilla\`.

Windows puede mostrar "Windows protegió su PC" porque el ejecutable aún no está firmado: *Más información* →
*Ejecutar de todas formas*.

### Reportar problemas
Incluye la versión (título de la ventana), qué hiciste y el archivo `kabrilla.log`.
