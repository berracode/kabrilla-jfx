## Kabrilla 1.0.0-rc.4 — Release Candidate

Cuarta versión candidata. Corrige el problema conocido de la rc.3 con las credenciales vencidas.

### Cambios
- **Credenciales renovadas sin reiniciar**: si las credenciales AWS vencen y pegas unas nuevas con
  "Agregar credenciales", la app las usa de inmediato. Antes había que cerrar y abrir la app (o esperar ~14 minutos).
- Los namespaces del panel izquierdo que fallaron por credenciales vencidas se recargan solos al guardar las nuevas.
- En una pestaña de deployment ya abierta basta con **Refrescar** (Pods) o reanudar el stream (Logs): usa las
  credenciales vigentes.
- Mensajes de error claros y uniformes. Por ejemplo: "No se pudo listar los deployments de pagos-qa (HTTP 401):
  credenciales AWS vencidas o inválidas: pega unas nuevas con "Agregar credenciales" y reintenta".
- Volver a expandir un namespace que falló reintenta la carga (antes también se recargaba al colapsarlo).

### Instalación
1. Descarga `kabrilla-1.0.0-rc.4-win-portable.zip` (abajo, en *Assets*) y descomprímelo.
2. Ejecuta `Kabrilla\Kabrilla.exe`. No necesita Java instalado.
3. Requisitos: **AWS CLI v2** en el PATH y `~/.kube/config` con los clusters EKS
   (`aws eks update-kubeconfig --name <cluster> --region <region>`).

Si vienes de una rc anterior: borra su carpeta y descomprime esta. Tus namespaces y credenciales siguen en
`%USERPROFILE%\.kabrilla\`.

Windows puede mostrar "Windows protegió su PC" porque el ejecutable aún no está firmado: *Más información* →
*Ejecutar de todas formas*.

### Reportar problemas
Incluye la versión (título de la ventana), qué hiciste y el archivo `kabrilla.log`.
